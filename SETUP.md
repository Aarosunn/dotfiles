# Setup on a fresh install

## 1. Link configs
```
git clone <this repo> ~/Dev/dotfiles
cd ~/Dev/dotfiles && stow -t ~ --no-folding base classic
```

## 2. Packages
```
paru -S stow git-delta rofi cliphist wl-clipboard awww yazi ghostty btop \
        papirus-icon-theme sassc gtk-engine-murrine \
        wlctl-bin bluetui dragon-drop
paru -S aur/quickshell-git caelestia-shell
```

## 3. GTK theme (Tokyo Night Moon)
```
git clone --depth 1 https://github.com/Fausto-Korpsvart/Tokyonight-GTK-Theme.git /tmp/Tokyonight-GTK-Theme
cd /tmp/Tokyonight-GTK-Theme/themes && ./install.sh -c dark --tweaks moon -l
gsettings set org.gnome.desktop.interface gtk-theme 'Tokyonight-Dark-Moon'
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
gsettings set org.gnome.desktop.interface icon-theme 'Papirus-Dark'
```
